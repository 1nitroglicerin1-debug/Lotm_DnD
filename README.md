# 🕯 Повелитель Тайн · Нейросетевая RPG

Telegram-бот + Mini App: живая настольная ролевая игра по вселенной **«Lord of the Mysteries»** с ИИ-Мастером, 22 каноничными Путями Потусторонних (Посл. 9 → 0) и механикой D&D 5e (d20, проверки, слоты, преимущества).

## Что внутри

**Сюжет с ИИ-Мастером** — Мастер пишет сцены, реагирует на любые действия, ведёт три дела одновременно (улики, NPC, летопись) и предлагает варианты с честными шансами успеха. Игрок может нажимать кнопки **или просто писать свои действия текстом** — классификатор сам подберёт навык и бросит d20.

**Конструктор Потустороннего** — 22 Пути × ветви способностей на Посл. 9, 8 предысторий с бонусами и снаряжением, 6 регионов старта (Тинген, Бэклунд, Трир, Баям…), Point-Buy 27 очков, навыки + компетенция, личная квента.

**Прогрессия** — переваривание зелья, ритуалы повышения Последовательности, Рассудок, Ячейки силы, механики Путей, Запечатанные Артефакты с проклятиями, соло-бои 1-на-1.

**Монетизация (Telegram Stars)** — пакеты ходов, Печати Судьбы (переброс провала с Преимуществом), Шкатулки Артефактов, VIP «Святилище Серого Тумана». Плюс подписки через Lava.top (webhook) и рефералка «Клуб Таро».

**Инструменты мастера** — проверка навыков, спасброски, инициатива, порядок хода, полноценный бой по раундам, HP/состояния/слоты/отдых, назначение ДМа чата, режим тишины, поиск по анкетам и админ-панель.

## Стек

- **aiogram 3** (long polling) — Telegram-бот, FSM поверх SQLite
- **FastAPI + uvicorn** — API и Mini App (`static/index.html`)
- **SQLite** — вся база в `data/bot.db` (WAL, без внешних зависимостей)
- **LLM через OpenAI-совместимый API** (proxyapi / DeepSeek) — JSON-схема ответа, ретраи, fallback-сцены
- **Данные игры** — `lotm_data.py`, `lotm_paths_a..d.py`: 22 пути, тиры 9→0, черты, механики, предыстории, регионы

## Быстрый старт (Windows)

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # впишите BOT_TOKEN, ADMIN_IDS, LLM_API_KEY
python main.py
```

Локальный веб-клиент: http://localhost:8000 (вне Telegram работает демо-режим).

## Запуск на сервере (Ubuntu)

```bash
# systemd-сервис
cp dnd-bot.service /etc/systemd/system/
systemctl enable --now dnd-bot

# или Docker
docker compose up -d --build
```

Для публикации Mini App укажите в `.env` публичный HTTPS-адрес:
```
WEBAPP_URL=https://ваш-домен
```
(бот автоматически покажет кнопку «Открыть Веб-Терминал»). Проще всего — обратный прокси Caddy (`reverse_proxy localhost:8000`) или cloudflared-туннель.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | Telegram ID администраторов через запятую |
| `LLM_API_KEY` / `LLM_API_URL` / `LLM_MODEL` | доступ к ИИ-Мастеру (OpenAI-совместимый API) |
| `WEBAPP_URL` | публичный HTTPS-адрес Mini App |
| `TRIBUTE_LINK` | необязательная ссылка «Поддержать автора» |
| `DEV_MODE` | 1 = панель разработчика в веб-клиенте (только для тестов!) |
| `GLOBAL_FREE_DAILY_CAP` | дневной бюджет бесплатных ИИ-ходов всего сервера |

## Частые проблемы

- **Бот молчит в группе** → выключите Group Privacy в BotFather и добавьте бота заново.
- **ИИ-Мастер пишет заглушку** → проверьте `LLM_API_KEY` и модель (см. комментарий в `.env.example`).
- **Кнопка Mini App не видна** → заполнен ли `WEBAPP_URL` (обязательно HTTPS)?
- **База** — один файл `data/bot.db`, бэкап: `cp data/bot.db backup-$(date +%a).db` по cron.
