# Lotm_DnD

Бот для текстовых ролёвок с механиками D&D 5e: анкеты персонажей с модерацией и броски кубов в чате.

## Возможности

**Игрок (в личке с ботом)**
- `/newchar` — пошаговая анкета: имя, раса, класс, уровень, 6 характеристик, навыки (владение / компетенция), спасброски, текст анкеты, изображение
- `/me` — своя анкета и кнопка «✏️ Изменить»
- правка текста и картинки не требует повторной проверки; правка уровня, характеристик, навыков и спасбросков отправляет анкету на повторное одобрение

**Админ**
- `/admin` — списки анкет (на проверке / одобренные / отклонённые / все), постранично
- `/find текст` — поиск по имени, расе, классу, @username или ID
- одобрить, отклонить (с причиной, игрок получает сообщение), изменить любое поле, удалить
- о новых и изменённых анкетах бот сам пишет всем админам

**Чат ролёвки (бот добавляется в группу)**
- `/check Скрытность [преим|пом] [+N]` — проверка навыка
- `/check Сила` — проверка характеристики
- `/save Ловкость` — спасбросок (мастерство, если выбрано в анкете)
- `/init` — инициатива
- `/iti` — порядок хода (очередь сохраняется при /init)
- `/roll 2d6+3` — любой бросок (`d20`, `4d8-1`, `1d20+1d4+2`, можно писать `2к6`)
- `/roll d20 преим [+N]` — d20 с преимуществом/помехой и бонусом
- `/last` — последние броски (в группе — общие, в личке — свои)
- `/skills` — таблица всех бонусов персонажа
- `/help` — справка

**Бой и здоровье**
- `/hp` — HP, временные HP, КД, кости хитов (+ полоса HP)
- `/hp -5` — урон (временные HP поглощаются первыми); `/hp +3` — лечение
- `/temp 5` — временные HP (заменяют, только если больше текущего)
- `/death` — спасбросок смерти (при 0 HP)
- `/cond отравлен` / `/cond -отравлен` — накладывать/снимать состояния
- `/slots` — слоты заклинаний; `/slots 3 -1` — потратить, `/slots 3 +1` — вернуть
- `/rest short` / `/rest long` — отдых (кости хитов, полное восстановление слотов)
- `/dm @username` — назначить Мастера чата (контролирует HP/состояния/слоты всех)
- `/encounter start|next|end` — полноценный бой по раундам (кто ходит, `/next`, статус `/encounter`)
- полноценный бой: `/init` → `/iti` → `/encounter start` → `/encounter next` → `/encounter end`

Боевые характеристики (HP, КД, кости хитов, слоты) вычисляются автоматически при одобрении анкеты по классу, уровню и Телосложению.

📖 **Подробное руководство для новичков по шагам — в файле [GUIDE.md](GUIDE.md).**

### Как считается проверка навыка
1. Бот ищет игрока в БД по Telegram ID.
2. Анкета не одобрена → «Твоя анкета ещё не одобрена».
3. По таблице соответствий определяется характеристика навыка (`rules.py`, словарь `SKILLS`).
4. Модификатор = (значение − 10) // 2.
5. Если игрок владеет навыком — добавляется бонус мастерства (при компетенции ×2).
6. Бонус мастерства = 2 + (уровень − 1) // 4.
7. Кидается d20 (2d20 при преимуществе или помехе; одновременно — гасятся).
8. Всё складывается (+ необязательный бонус `+N`).
9. Бот показывает кубик, все слагаемые и итог.

## Файлы
| Файл | Что внутри |
|---|---|
| `main.py` | запуск |
| `config.py` | настройки из `.env` |
| `rules.py` | формулы, таблица навыков, кубы, HP/урон/отдых/слоты (без Telegram) |
| `db.py` | SQLite: анкеты, журнал бросков, логи модерации, инициатива, бой, DM |
| `fsm_storage.py` | персистентное хранилище состояний форм (SQLite) |
| `ui.py` | карточка анкеты, клавиатуры, проверка ввода |
| `h_profile.py` | анкеты игроков |
| `h_admin.py` | админ-панель |
| `h_dice.py` | кубы в чате |
| `h_combat.py` | бой, HP, состояния, отдых, слоты |
| `test_rules.py` | тесты чистой логики правил |

Запуск тестов: `python -m unittest test_rules -v`

# Установка и запуск 24/7

## 1. Создать бота
1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя и username (на `bot` на конце). Сохраните **токен**.
2. Там же: `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off**. Без этого бот может не видеть команды в группе.
3. Узнайте свой Telegram ID: напишите **@userinfobot**. Если админов несколько — соберите ID всех.
4. Откройте своего бота и нажмите **Start** (иначе он не сможет вам писать уведомления).

## 2. Арендовать сервер (VPS)
Подойдёт любой дешёвый VPS с Ubuntu 22.04/24.04 (1 vCPU, 512 МБ–1 ГБ RAM, от ~3–5 €/мес: Hetzner, Timeweb, Selectel, DigitalOcean и т.п.). Открывать порты **не нужно** — бот сам ходит к Telegram (long polling). Вам понадобится IP сервера и пароль или SSH-ключ.

## 3. Загрузить бота на сервер
С вашего компьютера (Windows 10/11, macOS, Linux — в терминале/PowerShell), в папке с `dnd-bot.zip`:
```bash
scp dnd-bot.zip root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
```
(На Windows можно вместо scp использовать WinSCP/FileZilla.)

## 4. Установить и настроить (на сервере)
```bash
apt update && apt install -y python3-venv unzip
adduser --disabled-password --gecos "" bot     # отдельный пользователь для бота
mv /root/dnd-bot.zip /home/bot/
su - bot
unzip dnd-bot.zip && cd dnd-bot
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env
nano .env        # впишите BOT_TOKEN и ADMIN_IDS, сохранить: Ctrl+O, Enter, Ctrl+X
```

## 5. Пробный запуск
```bash
venv/bin/python main.py
```
В логе должно появиться `Бот запущен: @имя_бота`. Напишите боту `/start`. Остановить — `Ctrl+C`, затем `exit` (вернётесь в root).

## 6. Автозапуск 24/7 (systemd)
Под root:
```bash
cp /home/bot/dnd-bot/dnd-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now dnd-bot
systemctl status dnd-bot        # должно быть active (running)
```
Теперь бот стартует вместе с сервером и перезапускается после падений.
Логи: `journalctl -u dnd-bot -f`

## 7. Подключить к чату ролёвки
1. Добавьте бота в группу (участники → добавить).
2. Рекомендуется сделать его администратором (не обязательно, но так надёжнее).
3. Если Group Privacy включали уже после добавления — удалите бота из группы и добавьте снова.
4. Проверьте: `/roll d20`.

## 8. Резервные копии
Вся база — один файл `data/bot.db`. Ежедневная копия (под пользователем `bot`, `crontab -e`):
```
0 4 * * * cp /home/bot/dnd-bot/data/bot.db /home/bot/backup-$(date +\%a).db
```
Скачать копию на компьютер: `scp bot@IP_СЕРВЕРА:/home/bot/backup-Mon.db .`

## 9. Обновление бота
Загрузите новые файлы на сервер (поверх старых, `.env` и `data/` не трогать) и перезапустите:
```bash
systemctl restart dnd-bot
```

## Вариант через Docker (вместо шагов 4–6)
```bash
apt update && apt install -y docker.io docker-compose-v2 unzip
unzip dnd-bot.zip && cd dnd-bot
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```
`restart: unless-stopped` обеспечивает автозапуск; база лежит в `./data`.

## Частые проблемы
- **Бот молчит в группе** → выключите Group Privacy в BotFather и переприсоедините бота к группе.
- **Админу не приходят уведомления** → админ должен хотя бы раз нажать Start у бота.
- **`Unauthorized`** в логе → неверный токен в `.env`.
- **Команды работают, но бот отвечает «ещё не одобрена»** → анкету должен одобрить админ (`/admin`).
- Состояние диалога (на каком шаге анкеты человек) хранится в `data/fsm.db` и переживает рестарт бота. Готовые анкеты лежат в `data/bot.db` и не теряются.
